# Advocacia Mario Santos | Direito Trabalhista e Previdenciário

Website institucional de alta performance desenvolvido para a **Advocacia Mario Santos** com Next.js 16 (App Router), React 19, Tailwind CSS v4, GSAP 3 e Lenis Smooth Scroll.

## 🚀 Tecnologias

- **Framework**: Next.js 16.3.5 (Turbopack)
- **UI**: React 19 + Tailwind CSS v4
- **Tipografia**: Inter + Manrope
- **Paleta 60-30-10**: Azul-Marinho Profundo (`#061426`), Azul Secundário (`#17283D`), Dourado Institucional (`#D99A3A`) e Branco Premium (`#F5F5F3`)
- **Animações**: GSAP 3.15 + ScrollTrigger + @gsap/react + Lenis Smooth Scroll
- **Deploy**: Cloudflare Pages (`https://mariosantos.pages.dev`)
- **Conformidade Ética**: Provimento 205/2021 do CFOAB e Código de Ética e Disciplina da OAB

## 🛠️ Comandos

```bash
# Instalar dependências
npm install

# Rodar servidor local
npm run dev

# Gerar build estático para produção (pasta /out)
npm run build
```
